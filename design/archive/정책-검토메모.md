# 정책 열린 항목

정책 본문은 [moalog-policy.md](moalog-policy.md) 가 원본이다. 이 메모에는 아직 열린 것만 둔다.

- **개발 방향 확인**: 리포트 월별 집계 저장 · 누끼 기기 내 처리 · 공유 이미지 기기 내 생성 (비용 절감 목적)
- **Live 영상**: 자르기는 확정 (도감에서 제외, 공유 카드에서만). 남은 것은 공유 시 GIF/MP4 변환 가능 여부. Live 포토 크롭은 하지 않는다 (정책 §7).
- **기획 본문 반영**: 뱃지 추천 34개 (정책 §3) · 분류 9개(공통 + 8) · 요금제 29,000 / 3,300 / 58,000 로 Figma 기획 문서를 맞춘다. 대상: 문서 섹션 "정책 v4"(옛 XP · 뱃지 125개 · 그날 첫 포착 포함), 뱃지 도감 샘플 상태, 온보딩 이모지 규칙 표 확인
- **출시국 미정**: 어린이 기준은 국내 만 14세로 기본 적용 중. 해외 출시가 정해지면 국가별 기준을 다시 확인한다 (법무 검토 필요)
- **디자인 미정**: 실제 포착 결과 화면 · 등록 대기 상태 화면은 설계 전. B-10a · B-14 계열은 흐름 확인용
- **공유 설치 유도**: 공유 카드에 앱 링크나 QR을 넣을지 결정 필요
- **탐험맵 재제작**: 상세 ⋯의 "탐험맵에서 보기"가 연결할 화면이 없다
- **프로토타입 남은 곳**: Ⓐ 가입 약관 · Ⓑ 변형 화면 · D-03 · Ⓔ 팝업 연결 (00-working-index.md 참고)
- **등급 구간**: S = 90점 이상만 정해져 있다. A~F 점수 구간 결정 필요(포착 결과 · 상세 · 목록 엠블럼에 모두 쓰인다)
- **점수 표시**: 사진을 넘길 때 이름 줄 점수가 바뀌는 것은 정책에만 있고, 디자인 상태 화면 숫자는 아직 93으로 같다
