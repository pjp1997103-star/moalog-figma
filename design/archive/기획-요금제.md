## 2. 무료 vs 이용권

| 항목 | 무료 | 이용권 (구독 · 영구) |
|---|---|---|
| 도감 칸 | 10칸 | 무제한 |
| 포착 점수 · 백과 | 10칸까지 | 모든 생물 |
| 사진 저장 | 압축본 | 원본 + Live 포토 |
| 뱃지 · 경험치 · 리포트 | 동일 | 동일 |

- 핵심 가치 = **칸 제한 해제**. 원본 · Live 저장이 두 번째.
- 뱃지 · XP · 리포트는 무료와 같다 (재미 장치는 막지 않는다).

## 3. 구독 종료 규칙

- 한 번이라도 구독하면 **모은 도감은 평생 남는다** (열람 · 원본 그대로).
- 종료 후 **새 생물 등록**은 무료 기준(10칸)으로 돌아간다. 이미 10칸을 넘었으면 새 등록 잠김 (예: "새 생물 등록 잠김 · 37 / 10칸").
- 이미 모은 생물 **다시 찍기는 계속 가능**.
- 해지해도 결제 기간 끝까지 그대로 쓴다.
- 해지는 스토어로 이동해서 한다.

## 4. 결제 계기 (전환 지점)

| 순위 | 순간 | 규칙 |
|---|---|---|
| ★ 1 | **10칸이 찬 뒤 새 생물을 찍었을 때** | 가장 중요한 결제 순간. 아래 상세 |
| 2 | 도감 홈 상단 | `✦ Upgrade` 버튼 항상 노출. `n / 10칸` 미터, **8칸부터 "2칸 남았어요" 강조** |
| 3 | 원본 · Live 잠금 | 무료는 Live 저장 안 함 · 압축본 표시 → "이용권 보기" |
| 4 | 구독이 끝난 뒤 | 종료 배너 + 등록 잠금 바 + "다시 구독" |

### ★ 10칸 가득 → 새 생물 포착 (P-2)
1. **촬영은 막지 않는다.** 칸이 가득 차도 포착 버튼은 그대로.
2. **식별 결과는 먼저 다 보여 준다** (가치 먼저): NEW 배지, 이름, 분류, 학명, 포착 점수.
3. 그 아래 "도감에 남은 칸이 없어요" 카드 + 꽉 찬 10칸 미터.
4. "도감에 등록하기" → 결제 유도 시트
   - 타이틀: "도감 10칸이 가득 찼어요 · {생물명}을 11번째 칸에 넣으려면"
   - 내 10칸 미리보기 + 방금 찍은 생물(잠금 · NEW)
   - 플랜 요약: 연간(기본) / 월 / 영구
   - CTA "칸 제한 풀고 등록하기" → 스토어 결제 → **바로 등록 완료**
   - "나중에" → **등록 대기함**에 보관, 구독하면 바로 등록 (정책 §4 확정: 기간 · 개수 제한 없음, 구독 시작 시 포착 날짜순 자동 등록)
5. "종이 틀렸다면 직접 고르기"로 바꿔도 칸이 필요한 건 같다.
6. 등록 완료: NO.011 카드 + 원본 · Live 배지, "11칸 · 제한 없음", 분류 수집 뱃지가 있으면 함께.

## 5. 요금제 화면 (P-1)

- 위: 무료 vs 이용권 비교 (히어로 카드는 **내가 모은 카드**, 없으면 샘플)
- 아래: 연간 · 월 · 영구 선택. **연간이 기본 선택**
- CTA 문구는 선택에 따라 바뀐다 ("연간 29,000원으로 시작하기" / "58,000원으로 평생 이용하기")
- 보조 행동: "무료 10칸으로 먼저 써 볼게요", 구매 복원 · 이용약관
- 결제 완료: 카드 연출 + "이제 도감 칸 제한이 없어요" → 도감 보러 가기
- 이용권 관리: 이용 중 카드(만료일), 영구로 바꾸기(바꾸면 연간 해지 안내), 구독 해지(스토어)
