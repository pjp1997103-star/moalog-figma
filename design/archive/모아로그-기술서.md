## 1. 레벨 · XP

### 레벨 계산
- 레벨은 누적 XP로만 정한다. 감소 없음.
- 레벨 n 에 도달하는 누적 XP = `(n − 1) × (5n + 20)`
- 현재 XP 에서 레벨 = 누적 XP ≤ 현재 XP 를 만족하는 가장 큰 n

| 레벨 | 누적 XP | 칭호 단계 |
|---|---|---|
| 1 | 0 | 새내기 (1–4) |
| 5 | 180 | 관찰자 (5–9) |
| 10 | 630 | 숙련가 (10–19) |
| 20 | 2,280 | 달인 (20–29) |
| 30 | 4,930 | 전설 (30–) |

### XP 지급 규칙

| 활동 | XP | 상한 | 구현 메모 |
|---|---|---|---|
| 포착 (도감 등록) | +10 | — | 포착 1건마다 (같은 종 재포착은 0 · 정책 §2) |
| 새로운 종 | +20 추가 | — | 종마다 최초 1회. 합계 +30 |
| 일일 퀘스트 완료 | +10 | 하루 3개 · 최대 30 | 풀 12개 (정책 §12). "한 컷 명품"(90점 이상)이 매일 반복 가능 |
| 뱃지 획득 | 동 +10 · 은 +30 · 금 +50 · 레전드 +100 | — | 뱃지 등급별 (확정 2026-11-13) |
| 분류 세트 완성 | 없음 | — | 세트 완성 보상은 두지 않는다 (정책 §2) |

- 탐험맵 메모 · 자랑하기 · 척척박사 질문 등 행동 보상은 모두 퀘스트로 준다 (별도 XP 없음).

### 칭호
- 칭호 = [단계] + [탐험가 유형]. 예: "숙련가 조류 탐험가"
- 단계는 레벨로 자동 결정. 유형은 온보딩에서 고르고 리포트(D-02)에서 바꾼다. 미선택이면 "만능".
- 유형을 바꿔도 레벨·XP·뱃지는 그대로다. 바뀌는 것은 이름표와 화면 강조색뿐.

### 레벨업 연출
- 일반 레벨업: Level Card 의 LEVEL UP 표시만.
- 칭호 단계가 바뀌는 Lv.5 · 10 · 20 · 30: 전체 화면 연출 + 공유 (칭호 공유 시기는 추후).

## 2. 분류 · 뱃지

- 분류는 8개로 고정: 식물 · 곤충 · 조류 · 포유류 · 양서·파충류 · 어류 · 무척추동물 · 균류. (유형은 만능 + 8 = 9개. 나비 · 잠자리는 곤충 하위.)
  온보딩, 리포트, 뱃지, Figma `6. Categories` 변수 모드가 같은 목록을 쓴다. 글자 하나도 다르면 안 된다.
- 뱃지 구성은 **추천 34개** (공통 10 + 분류 8 × 3, 레전드 1개). 개수는 최종 조정 가능 (정책 §3 · §11). 기존 안(125개 · 142개)은 폐기. 잠긴 뱃지도 조건과 함께 모두 공개한다.
- 뱃지는 수집품이다. 승급 조건이 아니며 얻으면 XP만 준다.
- 뱃지 등급 4단계: 동 +10 · 은 +30 · 금 +50 · 레전드 +100 (확정). 화면 표시는 **금·은·동 테두리 색 + 아이콘 모양**이 주이고, "+XP" 숫자는 뱃지 상세에서만 보인다 (정책 §3).
- 뱃지 상태 3개:
  - 획득
  - 진행 중: 현재 / 목표 표시
  - 잠김: 조건과 XP는 미리 공개
- 진행도는 **모아로그 카메라로 포착한 기록만** 센다. 앨범 가져오기는 포함하지 않는다.

### 「곧 열리는 뱃지」 (리포트 하단)
- 항상 3개.
- 정렬: 진행률(현재 / 목표) 높은 순 → 같으면 XP 작은 순.
- 진행 중 뱃지가 3개 미만이면 잠김 뱃지 중 XP 작은 순으로 채운다. 빈 칸은 만들지 않는다.
- 더 보기 → 업적 뱃지 보관함(D-08, "보관함 N / 34" 형식. 개수 확정 전에는 N만 표시).

## 3. 리포트 (D-01)

### 섹션 순서
Level Card → 누적 숫자 3개 → 월별 기록 → 분류 비중 → 베스트 포착 → 키워드 TOP5 → 곧 열리는 뱃지

### 규칙
- 리포트는 최근 6개월 화면 하나뿐. "지난 달 리포트 보기(Pro)" 줄은 없다.
- AI 요약 문장은 쓰지 않는다.
- 연속 방문은 리포트가 아니라 출석 시트(E-07 · E-14 · E-15)에서 보여준다.
- 화면 강조색은 현재 탐험가 유형의 Categories 모드를 따른다. 만능은 `all` 모드(brand/primary).

### 월별 기록 표시

| 상황 | 표시 |
|---|---|
| 기록 0건 | 빈 상태 (D-03) |
| 첫 달 | 이번 달 막대 1개 + "다음 달부터 지난달과 비교할 수 있어요". 증감 문구 숨김 |
| 2–6개월 | 기록 시작 달부터 왼쪽부터. 오른쪽 위 "지난달보다 ±N" |
| 7개월 이상 | 최근 6개월만. 가장 오래된 달이 밀려난다 |
| 기록 없는 달 (중간) | 막대 높이 0 + "0" 표시 (건너뛰지 않음) |

- 막대 6개는 같은 폭, 간격 10.
- 이번 달은 오늘까지 누적값을 진하게, 지난 달은 35% 투명.
- 막대 높이 기준은 표시 중인 달의 최댓값.
- 6개월보다 오래된 기록은 리포트에 보이지 않는다. 도감에는 남는다.

### 분류 비중
- 도넛 + 범례 8줄. 조각·점 색은 각 분류의 Categories 모드.
- 가운데 숫자 = 도감 종 수.
- 만나지 못한 분류도 0종으로 범례에 남긴다.

### 빈 상태 (D-03)
- 구조는 D-01과 같다. 데이터 없는 섹션은 회색 자리 표시 + 안내 한 줄.
- 베스트 포착 · 키워드는 숨긴다.
- 「곧 열리는 뱃지」는 쉬운 뱃지 3개(잠김, 0 / 목표)로 채운다.
- 주 행동은 "첫 생물 포착하러 가기" 하나.

## 4. 디자인 구현 규칙 (Figma)

- 뱃지 색: `7. Badge Tier` 모드를 인스턴스에서 고른다. 모드 이름은 확정 등급에 맞춰 xp-10 · xp-30 · xp-50 · xp-100으로 바꾼다 (현재 Figma는 xp-60 · xp-150 상태라 수정 필요). fill 직접 수정 금지.
- 분류 색: `6. Categories / Color` 를 프레임 모드로 바꾼다.
- 나머지 색은 Semantic 변수만. hex 직접 입력 금지.
- 간격 · 패딩 · radius · 선 두께는 `2. Spacing & Sizing` 변수만 (gap/* · padding/* · radius/* · border-width/*). 척도에 없는 값은 가까운 토큰으로 맞춘다.
- Home Indicator: 전체 화면(852)마다 맨 위 1개, 바닥 고정. 시트·팝업 화면은 배경 화면의 것을 숨기고 맨 위 1개만. 시트·카드 컴포넌트 단독에는 넣지 않는다.
- 아이콘: 카드·목록의 이모지는 TOSS Face Icons 컴포넌트만 쓴다. 분류 이모지 매핑은 아이콘·에셋 라이브러리(`3003:56145`) 의 「이모지별 명칭 지정」을 따른다.

## 4-1. 사진 · 어린이 · 커뮤니티 (확정)

- **사진 자르기**: 도감에서는 하지 않는다. 도감 원본은 크롭하지 않은 첫 이미지를 1:1로 보관한다. 자르기는 공유 카드를 만들 때만 쓴다. 동식물 식별용 객체 탐지 크롭은 기기 내부에서만 하고 기록하지 않는다.
- **어린이 기준**: 기본 만 14세 미만 (국내 기준). 출시국 확정 시 재확인.
- **14세 미만 커뮤니티**: 메모 · 하트 · 댓글 쓰기 금지, 열람만 허용. 프로필 비공개, 랭킹 제외, 외부 공유 금지.
- 14세 미만 퀘스트 대체: #10 → 사진 자세히 보기, #11 → 이름 확인하기, #12 → 리포트 확인하기 (정책 §12).

## 5. 화면 · 상태 목록 (기획 확인용)

- 흐름: Ⓐ 온보딩 → Ⓑ 포착 → Ⓒ 도감 → Ⓓ 리포트 → Ⓔ 레벨·뱃지·출석 → Ⓕ 공유
