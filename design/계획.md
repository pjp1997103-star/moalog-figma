# 모아로그 · 제품 계획 (초안)

최종 갱신: 2026-11-11 · 상태: 방향 합의 전 초안
화면 번호와 레이어 이름은 작업하면서 바꿔도 된다. 이 문서는 "무엇을 왜"만 정한다.

---

## 1. 목표

- 한 줄: 밖에서 본 생물을 찍으면 **내 도감이 채워지는** 앱. 모으는 재미가 계속 돌아오게 만든다.
- 성공 기준
  - 첫 포착까지 걸리는 시간: 가입 후 60초 이내
  - 첫 주 재방문율 (D7) 과 포착 습관 (주 3회 이상)
  - 무료 → 프리미엄 전환율 (도감 가득 참 · 공유 · 척척박사 한도 순간에 제안)
  - 공유 발생률 (카드 공유 → 유입)
- 전 세계 사용: 한국어 우선이지만 문자열·날짜·단위·통화를 처음부터 다국어 구조로 만든다. 한국어 길이 기준이 아니라 영어·독일어 등 긴 문장을 기준으로 레이아웃을 검증한다.

## 2. UX 원칙 (모든 화면에 적용)

1. **첫 포착이 최우선**: 가입 직후 첫 화면에서 카메라가 바로 열리는 흐름. 질문은 줄이고, 나머지 설정은 나중에 묻는다.
2. **보상은 바로**: 포착 직후 XP·새 종·뱃지가 같은 화면에서 보인다. 기다리게 하지 않는다.
3. **빈 칸이 욕구를 만든다**: 도감의 잠긴 칸(실루엣)과 "다음 목표"를 항상 보여준다.
4. **한 화면 한 행동**: 빈 상태·결과·업그레이드 화면마다 주 행동 버튼은 하나.
5. **전환은 욕구의 순간에**: 프리미엄은 "더 찍고 싶을 때"(무료 횟수 초과, 도감 가득 참, 새 종 발견 직후)에 제안한다. 설정 메뉴나 온보딩에서 강하게 밀지 않는다.
6. **공유는 자랑거리**: 카드는 공유하고 싶은 모양으로 만든다 (메탈 카드 · 우표). 공유 버튼은 결과 화면에 항상 있다.
7. **말은 짧게, 글로벌하게**: 문장은 짧고 번역 가능하게. 아이콘·이모지 중심. 글자에 의존하는 정보는 한 번 더 시각으로 보여준다.
8. **접근성**: 색만으로 상태를 구분하지 않는다. 터치 영역 44pt 이상. 큰 글자 대응.

## 3. 재미 장치 (도감 중심)

| 장치 | 역할 | 현재 기획에서 |
|---|---|---|
| 도감 칸 (잠김 · 실루엣) | 빈칸을 채우고 싶게 | C-01 목록 |
| 종 발견 보상 (포착 +10 · 새 종 +20) | 처음 보는 생물에 기쁨 | 포착 결과 B-10 계열 |
| 분류 뱃지 3단계 (첫 발견 · 베테랑 · 마스터) | 한 분류를 깊게 파는 성취 (세트 완성 보상은 없음) | 정책 §3 |
| 뱃지 (추천 34개) | 수집품, 얻는 순간 축하. 등급은 금·은·동(+레전드 1개), 잠긴 뱃지도 공개 | 정책 §3 · J-02 |
| 칭호 (단계 + 유형) | 나를 표현하는 이름(초보 · 관찰하는 · 숙련된 · 마스터 · 전설의). 레벨 도달 시 자동 부여, 칭호 단계는 전체 화면 축하 | 레벨 디자인 Figma v3 |
| 이스터에그 칭호 | 희귀 칭호 3~5개. 조건은 숨기고 달성 순간에만 보여줌 | 조건 미정 |
| 일일 퀘스트 (풀 12 · 매일 3개 랜덤) | 하루 할 일과 습관. 1개 10 XP | 정책 §12 |
| 출석 (연속 방문) | 매일 열 이유. 출석 시트 안에 오늘의 퀘스트 3개를 함께 보여준다 | 정책 §12 · 화면 번호는 v3에서 확정 |
| 탐험맵 | 내가 다닌 곳이 보이는 지도 | 재작성 대상 |
| 공유 카드 | 자랑하고 유입 만들기 | F 계열 |

추가로 검토할 것 (결정 필요): 희귀도 등급(흔함·드묾·전설) 표시, 시즌·계절 한정 종, 친구와 도감 비교.

## 4. 구매 전환 흐름

```
가입 (최소 입력) → 첫 포착 (카메라 바로) → 첫 보상 축하
  → 도감 한 페이지 채움 → 공유 1회 → 무료 한도 근접 알림
  → 프리미엄 제안 (욕구 순간) → 구매 → 결제 완료 후 바로 다음 포착
```

- 가입 방식은 소셜 로그인 하나를 기본으로, 이메일은 보조.
- 권한 요청(카메라 · 위치)은 필요한 순간에 한 번씩. 한꺼번에 묻지 않는다.
- 프리미엄 화면은 "지금 얻는 것"을 숫자와 예시로 보여준다. 가격은 지역 통화로.

## 5. 화면 범위 (현재 흐름 기준 정리)

| 영역 | 해야 할 것 | 우선 |
|---|---|---|
| Ⓐ 시작 · 온보딩 | 질문 축소, 첫 포착 연결 | 높음 |
| Ⓑ 포착 | 결과 · 새 종 · 실패 흐름 정리 | 높음 |
| Ⓒ 도감 | 실루엣 칸, 진행도, 검색 | 높음 |
| Ⓔ 레벨 · 칭호 · 뱃지 · 출석 | 칭호 5단계 배지(레벨 엠블럼 교체), 칭호 단계 전체 화면 축하, 퀘스트 카드 추가 | 높음 |
| Ⓕ 공유 | 카드 디자인 2종 완성 | 중간 |
| Ⓓ 리포트 | 정책대로 정리, 빈 상태 | 중간 |
| Ⓖ 앱 전체 (설정 · 프리미엄 · 알림 · 피드) | 신규 | 중간 |
| 탐험맵 | 재작성 | 중간 |
| Empty state | 화면별 최종안 1개씩 | 낮음 (각 화면과 같이) |

## 6. 진행 순서 (단계별 확인)

1. **합의**: 이 문서의 목표·원칙·전환 흐름을 확정한다. (지금 단계)
2. **흐름 재정의**: `02-structure/flows.md` 에 첫 포착 중심 흐름을 적는다. 화면 번호는 새로 정한다.
3. **핵심 루프 먼저**: 가입 → 첫 포착 → 보상 → 도감 (Ⓐ · Ⓑ · Ⓒ). 이 3개가 끝나야 다음으로 간다.
4. **재미 장치**: 칭호 · 뱃지 · 출석 · 공유 (Ⓔ · Ⓕ).
5. **전환 · 부가**: 프리미엄 제안, Ⓖ 앱 전체, 탐험맵.
6. **문서화**: 정책 문서 하나를 최종 정리하고 Figma 문서 섹션에 펼친다.

각 단계가 끝나면 사용자 확인을 받는다.
