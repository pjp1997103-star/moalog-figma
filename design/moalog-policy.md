# 모아로그 · 개발 정책 (레벨 · 뱃지 · 리포트)

디자인과 개발이 같은 기준을 쓰기 위한 문서. Figma(모아로그 템플릿 · 「 Template 」 페이지)와 다르면 이 문서를 먼저 고치고 화면을 맞춘다.

최종 수정: 2026-11-10

---

## 1. 레벨 · 칭호

| 항목 | 정책 |
|---|---|
| 레벨 | XP 누적으로만 오른다. 절대 내려가지 않는다 |
| 필요 XP | Lv.n → n+1 = 20 + 10 × n · 누적 = (L − 1)(5L + 20) |
| 칭호 | [단계] + [탐험가 유형] (예: 숙련된 조류 탐험가) |
| 칭호 단계 | 레벨 구간으로 자동 결정: 초보 1–4 · 관찰하는 5–9 · 숙련된 10–19 · 마스터 20–29 · 전설의 30– |
| 탐험가 유형 | 온보딩에서 고르는 이름표. 만능 + 8분류 = 9개. 리포트에서 언제든 변경 |
| 유형 변경 | 레벨 · XP · 칭호 단계 · 뱃지 모두 그대로. 바뀌는 것은 이름표와 화면 강조색(Categories 모드)뿐 |
| 레벨업 연출 | 일반 레벨업은 Level Card의 LEVEL UP 표시만. 칭호 단계가 바뀌는 Lv.5 · 10 · 20 · 30 에서만 전체 화면(E-10) + 공유 |
| 칭호 설정 | 별도 화면 없음. 수식어는 레벨로 자동, 유형은 리포트 → 유형 변경(D-02). 설정 화면에는 "탐험가 유형 · 내 칭호" 표시만 |

## 2. XP

| 활동 | XP | 상한 |
|---|---|---|
| 포착 (도감 등록) | +10 | — |
| 새로운 종 | +20 추가 | — |
| S등급 (90점 이상) | +10 추가 | — |
| 그날 첫 포착 | +10 | 하루 1회 |
| 탐험맵 메모 · 공유 | +5 | 하루 20 |
| 뱃지 획득 | +10 / +30 / +60 / +150 | — |
| 분류 세트 11개 완성 | +100 | 분류당 1회 |

수치는 검증 전 제안값. 바꾸면 이 표와 J-02 보드 범례를 같이 고친다.

## 3. 분류

앱 전체가 같은 8개를 쓴다: 식물 · 곤충 · 조류 · 포유류 · 양서·파충류 · 어류 · 무척추동물 · 균류.
온보딩 관찰자 유형, 리포트 분류 비중, 뱃지 세트, Figma `6. Categories` 변수 모드가 모두 이 목록과 글자까지 같아야 한다.

## 4. 뱃지

- 총 125개 = 분류 뱃지 88개(8분류 × 11) + 공통 뱃지 37개(8묶음)
- 뱃지는 승급 재료가 아니라 수집품. 얻으면 XP만 준다
- XP 단계 4개: +10 브론즈 · +30 실버 · +60 골드 · +150 블랙 골드. 화면에는 색 이름 대신 "+XP" 숫자를 표시
- 상태 3개: 획득 · 진행 중(현재 / 목표 표시) · 잠김(조건과 XP는 미리 공개)
- 조건 판정은 모아로그 카메라로 포착한 기록만 센다

### 곧 열리는 뱃지 (리포트)

- 항상 3개 고정 (모바일 한 줄에 메달 3개)
- 정렬: 진행률(현재 / 목표) 높은 순 → 같으면 XP 작은 순
- 진행 중 뱃지가 3개 미만이면 잠긴 뱃지 중 쉬운 것(XP 작은 순)으로 채운다. 빈 칸은 만들지 않는다
- 더 보기는 헤더의 "보관함 N / 125" → 업적 뱃지 보관함(D-08)

## 5. 리포트 (D-01)

섹션 순서: Level Card → 누적 숫자 3개 → 월별 기록 → 분류 비중 → 베스트 포착 → 키워드 TOP5 → 곧 열리는 뱃지

- "지난 달 리포트 보기(Pro)" 줄은 없앤다. 리포트는 최근 6개월 화면 하나뿐

- AI 요약 문장("이번 달 이야기")은 쓰지 않는다
- 연속 방문은 리포트가 아니라 출석 시트(E-07 · E-14 · E-15)에서 보여 준다
- 화면 강조색은 현재 탐험가 유형의 Categories 모드를 따른다. 만능은 `all` 모드 = 브랜드 블랙(brand/primary)
- 온보딩에서 유형을 고르지 않으면 만능. 빈 상태의 "첫 포착" 메달은 만능 아이콘(🧭)
- Figma: D-01 · D-03 는 컴포넌트 세트 `Report/Main` 의 State=Data · Empty. 정책 원본은 Phase 2 섹션의 "J-01 v3 · 정책" 프레임

### 월별 기록

| 상황 | 표시 |
|---|---|
| 기록 0건 | 빈 상태 (D-03) |
| 첫 달 | 이번 달 막대 1개 + "다음 달부터 지난달과 비교할 수 있어요". 증감 문구 숨김 |
| 2–6개월 | 기록 시작 달부터 왼쪽부터 쌓는다. 오른쪽 위에 "지난달보다 ±N" |
| 7개월 이상 | 최근 6개월만. 가장 오래된 달이 밀려난다 |
| 중간에 기록 없는 달 | 막대 높이 0 + "0" 표시 (건너뛰지 않음) |

- 최대 6개월. 막대 6개는 같은 폭, 간격 10
- 이번 달은 진행 중 값(오늘까지 누적)을 진하게, 지난 달은 35% 투명
- 막대 높이 기준은 표시 중인 달 중 최댓값
- 6개월보다 이전 기록은 리포트에서 보여 주지 않는다 (도감의 포착 기록에는 남아 있다)

### 분류 비중

- 도넛 + 범례 8줄. 조각과 점 색은 각 분류의 Categories 모드
- 가운데 숫자 = 도감 종 수
- 만나지 못한 분류도 범례에 0종으로 남긴다 (모을 목표를 보여 줌)

### 빈 상태 (D-03)

- 리포트 구조는 D-01과 같다. 데이터가 없는 섹션은 회색 자리 표시로 두고 안내 한 줄
- 베스트 포착 · 키워드는 숨긴다
- 곧 열리는 뱃지는 쉬운 뱃지 3개(잠김, 0 / 목표)로 채운다
- 주 행동은 "첫 생물 포착하러 가기" 하나

## 6. Figma 변수 규칙

- 뱃지 색: `7. Badge Tier` 모드(xp-10 · xp-30 · xp-60 · xp-150)를 인스턴스에서 고른다. fill 직접 수정 금지
- 분류 색: `6. Categories / Color` 를 프레임의 모드로 바꾼다
- 나머지 색은 Semantic 변수만 쓴다. hex 직접 입력 금지
- Home Indicator: 전체 화면(852)마다 맨 위 레이어에 1개, 바닥 고정. 시트·팝업이 뜬 화면은 배경 화면의 것을 숨기고 맨 위 1개만. 시트·카드 컴포넌트 단독에는 넣지 않는다
- 간격 · 패딩 · radius · 선 두께는 `2. Spacing & Sizing` 변수만 쓴다 (gap/* · padding/* · radius/* · border-width/*). 척도에 없는 값(6 · 10 · 14 · 16 radius 등)은 가까운 토큰으로 맞춘다. 자주 필요하면 변수를 추가한다
